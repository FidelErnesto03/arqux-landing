3 · LA FORMA DE UN PAQUETE DE EVIDENCIA

Lo que tu auditor lee de verdad.

Un export firmado — hashes y procedencia, no tu contenido. Estructura ilustrativa:

// paquete-evidencia.json — ilustrativo { "alcance": "base:gobernanza · 2026-Q4", "entradas": 1843, "chain_head": "sha256:9f2c…c41d", "verificado": { "python": true, "go": true, "node": true, "rust": true, "bash": true }, "ventana": { "desde": "2026-10-01T00:00:00Z", "hasta": "2026-12-31T23:59:59Z" }, "firma": "ed25519:…", "verificar": "arqux evidence verify paquete-evidencia.json" }

El auditor contrasta el chain head contra los hashes de entrada y la firma — sin ver jamás la memoria cruda. Integridad y confidencialidad, desacopladas por diseño.
