Una idea, dos superficies, una fuente — escribe y las dos representaciones se actualizan. El codec real valida con loss==0; esta demo muestra solo el emparejamiento.

Señal, no relleno

Una idea por línea

Las normas viven en ideas tipadas, no en prosa. La densidad es una propiedad del formato, no una promesa de comprensión.

Microtokens

Las repeticiones se vuelven alias

Un átomo repetido tres veces o más se convierte en un alias de un token. La forma canónica, y su hash, no cambian.

Canónico y reversible

Mismos bytes en todas partes

La misma entrada produce los mismos bytes canónicos en todos los runtimes. HCORTEX es una representación, no una segunda fuente.

Herramientas de editor

arqux-cortex-viewer — el formato como superficie de trabajo.

Extensión para VS Code · v0.4.2 · Apache‑2.0 · VSIX desde el repositorio. Primero offline: cero telemetría, cero llamadas de red.

Ver el documento

Vista previa HCORTEX en vivo

Secciones, tablas y glosario se renderizan mientras escribes, con el sha256 canónico y un contador de pérdida. PlantUML y Mermaid se renderizan localmente como SVG.

Editar con guardas

Edición con guarda de pérdida

Las ediciones de tabla pasan por el codec y se abortan ante cualquier pérdida. Los errores llevan códigos del codec en la línea y columna exactas.

Más allá de un editor

cortex-ls

Un servidor de lenguaje stdio para diagnósticos, autocompletado, renombrado y validación de corpus. VS Code se conecta hoy; otros editores pueden conectarse.

Requiere codec-cortex ≥ 1.0.1; la cadena de herramientas resuelve Rust → Go → Python → Node. Instalación mínima: pip install codec-cortex. Código de la extensión, changelog y notas de seguridad →

¿Por qué no solo YAML/JSON/Markdown? ›
Pueden guardar datos, pero no tienen unidad de idea, ni capa de glosario local, ni expansión canónica — la densidad y la reversibilidad se vuelven accidentes de cómo escribes, no propiedades del formato. CORTEX las convierte en contrato. Los límites siguen aplicando: la densidad es una propiedad de la representación (bytes · tokens · repetición), no una afirmación de comprensión; las ventajas de tokens se publican con corpus neutral y límites declarados, según el charter del proyecto.
