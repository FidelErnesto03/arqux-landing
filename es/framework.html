QUÉ HAY ADENTRO

Cuatro piezas, un método.

01 · El formato CORTEX

Sigilos, secciones, dialectos, perfiles. Canónico, direccionable, legible por humanos. Cada documento es auto-descripto — su glosario viaja con él.

02 · El kernel de constitución

Axiomas, roles y workflows como estructura de carga — no una sugerencia en un prompt. Las reglas viven en secciones que el bootstrap siempre carga.

03 · La superficie MCP

Sesiones, tareas, evidencia, memoria — operaciones que tus agentes llaman por el protocolo que ya hablan. Sin SDK nuevo que adoptar.

04 · La suite de conformidad

Tests byte-exactos en Python, Go, Node, Rust y Bash. Si una superficie se desvía, el certificado falla — ese es el punto.

INSTALACIÓN

Una línea. El método en tu stack.

pip install arqux

Requiere Python 3.10+. El servidor MCP viene con el paquete. Las superficies Go, Node, Rust y Bash viven en el repo.

ORIGEN

Crecido en las trincheras, no en una pizarra.

ArqUX creció corriendo un workspace multi-agente real: 20+ proyectos gobernados, sesiones maratónicas reanudadas semanas después sin perder una sola directriz, y un códec de memoria que se ganó la certificación por el camino lento — 141/141, cinco runtimes, revisiones adversariales, hipótesis falsificadas. Antes de confiar en un nombre, el proyecto falsificó 46 marcas candidatas. Esa es la disciplina de la casa: medir, o no afirmar.
