Versiones

Dos canales, comandos exactos.

El paquete publicado y el repositorio no son la misma versión. Elige uno y comprueba la versión antes de ejecutar.

A

Paquete publicado

PyPI · 0.9.0

pip install arqux==0.9.0
arqux --version

Lo que `pip install arqux` resuelve hoy. Verificado 2026-11-18 · Linux · Python 3.11.12 · salida: arqux 0.9.0.

B

Repositorio fuente

GitHub · 1.0.0

git clone https://github.com/FidelErnesto03/arqux
python -m pip install -e .

Python ≥3.10, según pyproject.toml. Verificado 2026-11-18 · Linux · Python 3.11.12 · salida: arqux 1.0.0.

First run

Primer workspace gobernado

Ruta del repositorio 1.0.0. Estos comandos aparecen en arqux --help de 1.0.0; aquí están documentados, no ejecutados en esta entrega. El paquete 0.9.0 puede diferir.

01

Crea una carpeta

mkdir demo && cd demo

02

Inicializa el workspace

arqux init

03

Onboarding guiado

arqux quickstart

04

Genera las proyecciones

arqux sync-harnesses

05

Comprueba la deriva

arqux drift-check

Sin servidor y sin clave de API. Instalar no configura todos los clientes ni crea aprendizaje automáticamente; el comportamiento es de cada aplicación.

ArqUX

La arquitectura detrás del trabajo humano–IA. Framework open-source para trabajo de agentes gobernado — v1.0.0.

Nombre acuñado: “Arq” por arquitectura — la estructura que da forma a cómo se hace el trabajo; “UX” por la experiencia compartida entre personas y agentes de IA.
