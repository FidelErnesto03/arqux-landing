Verificado de extremo a extremo

Una primera tarea gobernada, desde una carpeta vacía.

Linux · Python 3.11.12 · ArqUX 1.0.0 en 3903339 · 2026-11-18. Solo la ruta CLI; sin llamada a un modelo.

Resultado

  • Artefactofirst-task.txt contiene hello-from-arqux.
  • Evidenciasha256:4340d832667bc0d34c6f232e7858cdf0ae070ac942e6c53e755f224b8ee9c594
  • TareaT-001 cerrada como done; evento PULSE SES001-E0002.

Condiciones

  • Clave de ejecuciónARQUX_EXECUTION_KEY estable entre comandos.
  • OrdenCrear → ejecutar → completar, con la sesión vinculada.
  • Aviso observadoEl lifecycle del timelog quedó pending: la operación no se registró en este timelog.
Secuencia completa de comandos
mkdir arqux-first && cd arqux-first
export ARQUX_EXECUTION_KEY=first-task-demo
arqux init
arqux project init name=Demo
arqux cycle create name=CYCLE-01 description="First governed task"
arqux call session.context_set project=Demo scope=CYCLE-01
arqux call task.create content='$1:{obj:"Create a first governed artifact",proc:["Write first-task.txt [exec:write_file path=first-task.txt content=hello-from-arqux]"],ac:["first-task.txt contains hello-from-arqux"],complexity:"simple"}'
arqux call task.run task_id=T-001
arqux call task.complete task_id=T-001 evidence="first-task.txt sha256=$(sha256sum first-task.txt | cut -d' ' -f1)"
cat first-task.txt

Esto prueba la ruta CLI gobernada en un workspace limpio. No prueba el razonamiento de un modelo ni garantiza que cada cliente reproduzca el mismo lifecycle del timelog.

El artefacto y la evidencia están completos. El aviso se refiere a la cobertura del timelog, no al estado de la tarea: revisa .arqux/timelog/SES001_*.cortex para inspeccionar el registro. Esta entrega no declara un comando de cierre.

La verificación está fijada a 3903339. El HEAD del repositorio puede ser más nuevo; repite la secuencia al actualizar el pin.

Conecta tu app

Apunta tu cliente al workspace.

arqux serve expone los handlers de gobierno por stdio. Lánzalo con el workspace como cwd; la configuración del cliente pertenece a cada app.

Claude Desktop

Añade el servidor a claude_desktop_config.json:

{
  "mcpServers": {
    "arqux": {
      "command": "arqux",
      "args": ["serve"],
      "cwd": "/path/to/workspace"
    }
  }
}

Cualquier cliente stdio

El mismo servidor, lanzado desde el workspace:

cd arqux-first
arqux serve

Un workspace por proceso.

OpenCode

opencode --instructions "$(cat AGENTS.md)"
