Governance for human–AI teams

Govern human–AI work from the project files agents read.

ArqUX is an open-source pre-release framework for organizing agent identities, project context, scoped work and reviewable evidence in a governed workspace. Agents that can access that workspace can share its local governance files. Cross-workspace synchronization is not included in this release.

The coordination problem

Work should not restart with every session.

Instructions, decisions and context scatter across chats, repositories, tools and people. A new agent or workstation can begin from a different local view of the same project.

The local-file model

One governed project. Instructions where agents can read them.

Today, arqux init creates a governed project directory with local instructions and artifacts. Agents that can access the same project can read its governance files. A service that propagates and reconciles policy across independent workspaces is a product direction, not a capability of v0.9.0rc3.

Codec‑CORTEX

Structured knowledge. Human-readable when you need it.

CORTEX is the structured source; HCORTEX is its paired human-readable rendering. The codec's strongest claim is technical and testable: deterministic, reversible transformations across supported surfaces. This page shows a static example, not a live conversion.

CORTEX · machine sourcerepository example · 0.1

Validated, not just parsed

Structure with rules

Sigils, sections and attributes are checked against the document's own glossary — invalid state fails with codes, not silent acceptance.

Canonical and reversible

Same bytes everywhere

The same entry produces the same canonical bytes across supported runtimes; round-trip is certified within the codec's scope.

One source, two surfaces

Machine and human

CORTEX for processing, HCORTEX for reading — paired by construction, not by a converter you maintain.

Why not just YAML/JSON/Markdown? They are configuration and prose formats; CORTEX is governed state that must be validated, canonicalized, rendered and verified. The codec's limits still apply: format behavior, not reasoning quality.

Evidence, with scope

Separate what is proven from what is being checked.

A test of Codec‑CORTEX does not certify Framework behavior or agent security. Each claim belongs to a component and a version.

Available evidence · Codec‑CORTEX

Reversible format, measured within scope.

The published certificate reports 140/140 cases for canonicalization and round-trip checks, plus parity across five implementations on the seed vector. These results do not certify ArqUX Framework behavior or prove that an LLM understands the format better.

Trust and limits

Know what is enforced—and what depends on the agent.

A written rule, a permission check and a human practice are different controls. ArqUX should make that difference visible.

01

Applied by code

Handler permissions, validation and state changes only where the release implements and tests them.

02

Read by the harness

Local instruction and context files shape an agent's work; they do not automatically guarantee obedience.

03

Owned by the team

Approval, review, synchronization and key handling depend on the documented workflow and its actual controls.

A hash can detect a mismatch against a trusted reference. It is not by itself a signature or an independent audit.
