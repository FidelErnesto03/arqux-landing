The problem

Context breaks in five ordinary ways.

The work survives. The reference that made it coherent does not.

  1. 01
    Between specialised agents

    An analysis agent and a graphics agent exchange context as prose. The original reading drifts and the criteria take a different shape.

  2. 02
    A change of harness

    The next harness reads the project’s code and documentation from scratch just to begin.

  3. 03
    The context window runs out

    Compression drops directives and guidelines. A summary is not enough; reading everything again exhausts the window again.

  4. 04
    Sharing a project

    Handing over a project with its context makes the other person evaluate it all over, with room for a different reading.

  5. 05
    Closing the day

    When the session or the app ends, the evolution so far — and the context that led there — is hard to recover.

In all five, the project keeps the output and loses the reference that connected it.
