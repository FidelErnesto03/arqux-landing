WHAT'S INSIDE

Four pieces, one method.

Sigils, sections, dialects, profiles. Canonical, addressable, human-readable. Every document is self-describing — its glossary travels with it.

02 · The constitution kernel

Axioms, roles and workflows as load-bearing structure — not a prompt suggestion. The rules live in sections the bootstrap always loads.

03 · The MCP surface

Sessions, tasks, evidence, memory — operations your agents call through the protocol they already speak. No new SDK to adopt.
