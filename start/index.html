Get started

How do I try it without guessing?

Two channels: the published package (0.9.0) and the repository (1.0.0). Pick one and follow its exact commands.

← Back to home

Installation channels

A

Published package

PyPI · 0.9.0

pip install arqux==0.9.0
arqux --version

What `pip install arqux` currently resolves to. Verified 2026-11-18 · Linux · Python 3.11.12 · output: arqux 0.9.0.

B

Source repository

GitHub · 1.0.0

git clone https://github.com/FidelErnesto03/arqux
cd arqux
python -m pip install -e .

Python ≥3.10, per pyproject.toml. Verified 2026-11-18 · Linux · Python 3.11.12 · full clone → cd → editable install · output: arqux 1.0.0.

First run

First governed workspace

Repository 1.0.0 path. These commands are listed by arqux --help in 1.0.0; they are documented here, not executed in this release. The 0.9.0 package may differ.

01

Create a folder

mkdir demo && cd demo

02

Initialize the workspace

arqux init

03

Guided onboarding

arqux quickstart

04

Render harness projections

arqux sync-harnesses

05

Check for drift

arqux drift-check

No server and no API key. Installing does not configure every client or create learning automatically; behaviour belongs to each app.
