How do I try it without guessing?

Two channels: the published package (0.9.0) and the repository (1.0.0). Pick one and follow its exact commands.

First run

First governed workspace

Repository 1.0.0 path. These five commands appear in arqux --help; the verified first-task sequence below is a separate CLI flow. The 0.9.0 package may differ.

01

Create a folder

mkdir demo && cd demo

02

Initialize the workspace

arqux init

03

Guided onboarding

arqux quickstart

04

Render harness projections

arqux sync-harnesses

05

Check for drift

arqux drift-check

No server and no API key. Installing does not configure every client or create learning automatically; behaviour belongs to each app.

Verified end to end

A first governed task, from an empty folder.

Linux · Python 3.11.12 · ArqUX 1.0.0 at 3903339 · 2026-11-18. CLI path only; no model call.

Full command sequence
mkdir arqux-first && cd arqux-first
export ARQUX_EXECUTION_KEY=first-task-demo
arqux init
arqux project init name=Demo
arqux cycle create name=CYCLE-01 description="First governed task"
arqux call session.context_set project=Demo scope=CYCLE-01
arqux call task.create content='$1:{obj:"Create a first governed artifact",proc:["Write first-task.txt [exec:write_file path=first-task.txt content=hello-from-arqux]"],ac:["first-task.txt contains hello-from-arqux"],complexity:"simple"}'
arqux call task.run task_id=T-001
arqux call task.complete task_id=T-001 evidence="first-task.txt sha256=$(sha256sum first-task.txt | cut -d' ' -f1)"
cat first-task.txt

This proves the governed CLI path in a clean workspace. It does not test a model's reasoning or guarantee that every client reproduces the same timelog lifecycle.

The verification is pinned to 3903339. The repository HEAD may be newer; re-run the sequence after updating the pin.

Connect your app

Point your client at the workspace.

arqux serve exposes the governance handlers over stdio. Launch it with the workspace as cwd; client configuration belongs to each app.

Claude Desktop

Add the server to claude_desktop_config.json:

{
  "mcpServers": {
    "arqux": {
      "command": "arqux",
      "args": ["serve"],
      "cwd": "/path/to/workspace"
    }
  }
}

Any stdio client

Same server, launched from the workspace:

cd arqux-first
arqux serve

One workspace per process.

OpenCode

Use the generated kernel as instructions:

opencode --instructions "$(cat AGENTS.md)"

Example from the framework README; verify it in your client.

Client behavior is external; ArqUX does not configure clients automatically. Source: MCP setup at 3903339 ↗.
